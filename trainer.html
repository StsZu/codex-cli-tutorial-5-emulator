Тренажер Codex CLI

Емуляція OpenAI Codex CLI без API: запуск із shell, slash-команди з офіційної довідки (command.md), дозволи й sandbox, сесії, codex exec. Команда зараховується лише в точному вигляді (або як явний синонім, напр. /exit = /quit, --yolo = довга назва прапорця). ↑/↓ — історія, Tab — автодоповнення.

Команди розділу

    Завдання: виконай усі команди розділу. Клік по команді вставляє її в поле — натисни Enter.

    Shell чи Codex? Команди codex … і git … — у shell (%). Slash-команди — лише всередині сесії (codex ›). Вийти з сесії: /quit.

    Тест: опис → введи команду; можна пропустити.
    stas@MacBook-Pro — demo-app — zsh
    shell
    stas@MacBook-Pro demo-app %
